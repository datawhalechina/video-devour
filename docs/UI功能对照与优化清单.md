# UI 效果图与实际功能对照

更新：2026-09-16。范围：湖蓝晨光、海岸暖光两套主题及已生成的 01–13 功能页效果图。

这里区分“已实现”“入口或交互不同”“尚未实现”“演示功能”。接口存在不代表本次已经完成真实视频生成验收。效果图中的示例内容、头像、连接状态和统计数不作为真实产品数据。

## 本轮已调整

- 主题选择仅保留在「设置 → 外观主题」，不占顶部导航。
- 外壳固定在视口内，桌面上下边距 1.125rem，左右 clamp(0.75rem, 2.5vw, 3rem)，与用户红框范围对齐；只允许内容区域滚动。自定义 CSS 尺寸使用 rem，Tailwind 构建样式和 Ant Design 运行时样式分别进行 rem 转换。
- 外壳、主导航保持固定；首页/列表在内容区滚动；桌面导入页左右面板独立滚动；设置分类和保存操作固定，表单滚动；阅读标题和文体切换固定，章节栏与正文分别滚动。
- 移除一级页面重复的返回条；详情页以「知识库 › 阅读」等路径返回确定的上级页面。
- 接入 Ant Design 5.29.3：Select、AutoComplete、Input.Password、Radio、Checkbox、消息提示、Pagination、Popconfirm 等，使用两套主题对应的颜色和表面样式。
- 模型配置按效果图压缩为「供应商/API Key、地址/模型」两行；模型既可选择，也可输入自定义值。
- 处理记录增加状态筛选、搜索、分页和删除确认。未执行任何实际删除。
- 编辑页移除重复的保存栏。原外层按钮使用初始内容，现保留编辑器内部以当前 Markdown 保存的入口。
- 编辑器的图片/视频地址输入改为界面弹窗。AI 润色入口明确标记为演示。

## 优先建议

1. **先统一阅读入口。** 同一视频从首页、知识库、历史记录进入，应得到同一个阅读页；编辑、导出、学习工具集中在这里。
2. **补上数据闭环。** 收藏、章节笔记、阅读位置、卡片掌握状态需要可保存的数据结构，不能只有图标。
3. **处理高影响交互。** 修复测试连接隐式保存、未保存离开保护、取消与删除混用，再接入真实 AI 润色。
4. **把学习工具改成统一页面。** 思维导图/图谱/卡片/测试使用同一套导航和数据，不再各自生成整页 HTML。

## 验证范围与限制

- 本轮验证对象是本地 UI、布局、键盘操作、只读加载及现有编辑器入口。
- 不以 AI 效果图的示例数字填充真实数据；原有两个示例文档的关键帧文件缺失，正文明确显示“原始图片文件不可用”。
- 未提交真实视频生成、未测试带密钥的模型请求、未保存测试用设置、未删除报告。
- 需要模型的功能在源代码中存在接口，不代表本轮已做端到端生成验收。
