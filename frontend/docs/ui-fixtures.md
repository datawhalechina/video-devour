# 独立 UI 测试数据

启动（项目根目录）：

```sh
.venv/bin/python scripts/preview_fixtures.py
```

访问 http://127.0.0.1:8001 。数据目录 `.ui-fixtures/`，不修改原服务的任务、报告和配置；前端与 8000 使用同一构建产物。启动脚本恢复样本文档，保留练习历史。主题偏好按浏览器端口分别保存，可在设置中切换。

## 查看入口

- `/library`：8 个视频，长短标题、特殊字符，卡片/列表、排序和搜索。
- `/library/video/fixture-video-01`：3 个版本；每版六种文体，12 个主章节、多级目录、图片、引用、表格和长正文。
- `/library/video/fixture-video-02`：代码示例。
- `/history`：17 条记录；10 已完成、4 模拟处理中（包括等待）、3 失败。进度固定，用于查看样式，并非真实任务。
- `/learn/fixture-01-3/mindmap`：多层导图，可缩放和查看节点。
- `/learn/fixture-01-3/graph`：13 个节点、24 条关系，包含跨章节关联。
- `/learn/fixture-01-3/cards`：37 张卡片，翻面、切换、掌握/待巩固标记。
- `/learn/fixture-01-3/quiz`：12 道单选、多选、判断题；可实际提交并查看评分。已提交一份包含正确、部分正确、错误和未答的测试答卷。
- `/report/fixture-01-3`：报告编辑、文体切换、耗时展示、导出入口。

## 范围

这些是明确标注的合成 UI 数据，不是实际视频处理结果。真实模型生成、上传处理、重新出题、重试和外部服务连接测试由独立预览服务拦截，并给出提示；题目判分使用原后端实现。PDF 等导出仍依赖本机原有依赖，未将按钮可见当作导出验证通过。

验证：构建通过；18 个版本/文体组合可读取；报告、导图、图谱、习题、耗时接口成功；习题提交判分成功；浏览器确认报告、习题、卡片、图谱、导图可展示。复杂导图适应画布后文字较小，可通过缩放查看，后续可用这个样本优化密集节点布局。

本地主服务 `/history?preview=states` 可叠加 6 条处理中示例（0%、12%、38%、76%、95%、99%）及 2 条失败示例，不写入任务数据库。点击“处理中”筛选查看；示例的操作仅用于界面演示，不运行模型。
