# UI 重构验证记录

日期：2026-09-16。本地 FastAPI 服务 `127.0.0.1:8000`，加载 Vite 构建产物。

## 已验证

- 前端构建通过；ESLint 无错误，原有 API、编辑器和阅读器等模块仍有 38 条警告。
- 6 项 Node 测试通过：日期分组、章节原文保留、空内容、生成文档的 JSON 安全解析、导图层级、循环关系与孤立节点。
- 浏览器检查 1586×992 与 390×844 两种视口；海岸侧栏与湖蓝顶栏均能切换。
- 工作台标题和输入固定；知识卡片与最近整理独立滚动。
- 知识库检索能返回后端结果，卡片/列表入口、圆角和本地收藏状态有效；收藏刷新后保留，验证后恢复原值。
- 设置类别可切换，保存入口位于分类栏右侧；窄屏分类横向滚动、表单局部滚动。
- 导入页在桌面分为无底卡的来源区与偏好面板，窄屏合为局部滚动的一列；字幕模式正确隐藏图文附加选项。
- 处理记录有日期分组、进度/失败样式及固定分页；预览数据有明确标记，不写入任务记录。
- 真实报告的学习卡片能翻看原文、切换和记录掌握状态；刷新持久化有效，验证后恢复原值。
- 习题本地样例覆盖单选、多选、判断题、逐题导航、交卷和答案解释；样例判题结果为 100%。此项不等于真实模型服务验证。
- 导图节点详情、缩放与适应画布有效；100% 时画布与 SVG 尺寸一致，外层文档没有额外滚动。
- 原报告阅读器能打开；导出弹窗正常展示、Escape 关闭。旧任务缺少耗时报告时显示后端错误。

## 明确未验证 / 剩余边界

- 没有调用收费模型、实际上传视频、修改 API Key 或保存服务配置。
- 本次没有桌面客户端安装包回归。SVG 导出采用完整画布尺寸与标准下载链接；内置浏览器未返回可核实的下载完成事件，文件落盘仍需在目标客户端确认。
- 原阅读器、上传、处理进度和编辑器保留兼容层，业务尚未全部拆分。
- 后端没有独立的取消/重试接口，UI 保留“查看进度 / 重新导入”。设置连接测试仍沿用原先先保存配置再测试的行为。
- 当前只有两条真实知识记录，不用示例内容填充真实知识库。示例学习页仅对本机地址启用。
- 本次完成的是主要页面与学习模块重构；不宣称所有页面已经像素级 1:1 验收。生成图中的头像、虚构统计及后来明确取消的元素不恢复。
