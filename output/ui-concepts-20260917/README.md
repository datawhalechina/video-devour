# VideoDevour · 三套蓝色 UI 方案

本目录为图像生成的主界面效果图，尚未接入当前应用。画面中的视频、日期、账号和数量均为示例。

| 方案 | 效果图 | 主要方向 |
| --- | --- | --- |
| A 冰川蓝 | `a-glacier.png` | 蓝白分栏，列表与笔记同屏，侧重阅读整理 |
| B 深海蓝 | `b-midnight.png` | 深蓝视频工作区，原视频、关键帧与笔记并列，侧重观看与理解 |
| C 晴空蓝 | `c-azure.png` | 亮蓝知识库，缩略图浏览与右侧预览，侧重收藏与查找 |

参考 ReadPo 产品演示的工作区组织方式，保留当前鲸鱼 Logo；没有采用毛玻璃效果。三套以相同的视频知识处理任务呈现不同的布局与视觉方向。

使用内置 image_gen 生成。该工具未暴露模型版本选择，不能确认或指定为用户所称的 image 2.5。完整提示词保存在 `prompts.json`。
